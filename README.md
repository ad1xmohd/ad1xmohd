## 🧩 Featured Projects

### 🔧 [Termix](https://github.com/ad1xmohd/Termix)
Termix is a lightweight, command-line tool designed to enhance terminal productivity. It provides quick access to common developer utilities, automation scripts, and system shortcuts — all from a single, customizable interface.

### ⚙️ [XcelSync](https://github.com/ad1xmohd/XcelSync)
XcelSync is an intelligent data synchronization and automation tool for Excel and CSV workflows. It streamlines file updates, merging, and cross-sheet syncing — perfect for managing datasets or automating spreadsheet tasks.
